# For encadeado

Exercícios que utilizam dois laços `for`, com um laço interno executado a cada repetição do laço externo, para construir matrizes, padrões e sequências bidimensionais.

Dos arquivos enviados, estes seis realmente utilizam laços encadeados. Os demais usavam apenas um `for` e não foram duplicados nesta pasta.

| Exercício original | Conteúdo praticado |
|---|---|
| 11 | Matriz numérica com quantidade variável de linhas e colunas |
| 12 | Tabela de multiplicação organizada em matriz |
| 14 | Triângulo crescente de estrelas |
| 18 | Quadrado numérico |
| 19 | Triângulo crescente de números |
| 20 | Tabuadas de 1 a 5 com laços encadeados |

## Como executar

```bash
javac PrimeiroSemestre/ForEncadeado/Exercicio11.java
java PrimeiroSemestre.ForEncadeado.Exercicio11
```
