# Funções

Exercícios desenvolvidos para praticar a criação e a chamada de métodos em Java, com parâmetros, retornos e divisão de responsabilidades.

| Exercício | Conteúdo praticado |
|---|---|
| 01 | Função que retorna o dobro de um número |
| 02 | Procedimento que exibe nome e idade |
| 03 | Função que calcula a média de três notas |
| 04 | Função booleana que verifica se um número é par |
| 05 | Menu com funções separadas para cada operação |
| 06 | Função que retorna o maior entre dois números |
| 07 | Função que calcula a área de um retângulo |
| 08 | Função booleana que verifica se um número é positivo |
| 09 | Função que calcula um desconto de 10% |
| 10 | Procedimento que exibe a tabuada de um número |

## Como executar

```bash
javac PrimeiroSemestre/Funcoes/Exercicio01.java
java PrimeiroSemestre.Funcoes.Exercicio01
```
