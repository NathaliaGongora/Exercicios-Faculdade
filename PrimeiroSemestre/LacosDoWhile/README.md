# Laços do...while

Exercícios desenvolvidos para praticar a estrutura de repetição `do...while`, na qual o bloco é executado pelo menos uma vez antes da verificação da condição.

| Exercício | Conteúdo praticado |
|---|---|
| 01 | Tabuada de um número |
| 02 | Soma de números até o usuário digitar um valor negativo |
| 03 | Média de números até o usuário digitar zero |
| 04 | Validação de senha |
| 05 | Calculadora com opção de continuar |
| 06 | Simulação de pagamento em máquina de venda |
| 07 | Menu de opções executado até o usuário escolher sair |
| 08 | Validação de número entre 1 e 10 |
| 09 | Entrada de números até a soma ultrapassar 50 |
| 10 | Jogo de adivinhação |

## Como executar

```bash
javac PrimeiroSemestre/LacosDoWhile/Exercicio01.java
java PrimeiroSemestre.LacosDoWhile.Exercicio01
```
