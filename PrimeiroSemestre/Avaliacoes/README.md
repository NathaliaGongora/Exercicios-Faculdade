# Avaliações

## AC1 — Calculadora de média semestral

Código desenvolvido durante a primeira avaliação de Construção de Algoritmos. A atividade reúne variáveis, entrada de dados com `Scanner`, operadores aritméticos, média ponderada, operadores lógicos e estruturas condicionais.

[Acessar código da AC1](AC1/Ac1.java)

## AC2 — Controle de estoque

Código desenvolvido para a segunda avaliação de Construção de Algoritmos. O programa cadastra produtos, armazena nomes e quantidades em vetores, classifica os níveis de estoque, calcula percentuais, gera um relatório geral e informa a necessidade de reposição.

[Acessar código da AC2](AC2/ControleEstoque.java)

## Como executar

### AC1

```bash
javac PrimeiroSemestre/Avaliacoes/AC1/Ac1.java
java PrimeiroSemestre.Avaliacoes.AC1.Ac1
```

### AC2

```bash
javac PrimeiroSemestre/Avaliacoes/AC2/ControleEstoque.java
java PrimeiroSemestre.Avaliacoes.AC2.ControleEstoque
```
