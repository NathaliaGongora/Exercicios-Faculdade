# Laços while

Exercícios desenvolvidos para praticar a estrutura de repetição `while`, utilizando condições de parada, contadores e acumuladores.

| Exercício | Conteúdo praticado |
|---|---|
| 01 | Soma de números até o usuário digitar um valor negativo |
| 02 | Média de números até o usuário digitar zero |
| 03 | Entrada de números até a soma ultrapassar 100 |
| 04 | Validação de senha |
| 05 | Simulação de pagamento em máquina de venda |
| 06 | Cálculo de fatorial |
| 07 | Contagem crescente até o número informado |
| 08 | Soma dos números de 1 até o valor informado |
| 09 | Tabuada de um número |
| 10 | Exibição dos números pares até o valor informado |

## Como executar

```bash
javac PrimeiroSemestre/LacosWhile/Exercicio01.java
java PrimeiroSemestre.LacosWhile.Exercicio01
```
