# Vetores

Exercícios desenvolvidos para praticar a criação, o preenchimento, a leitura e o processamento de vetores em Java.

| Exercício | Conteúdo praticado |
|---|---|
| 01 | Cálculo da média dos valores armazenados |
| 02 | Criação de um segundo vetor em ordem inversa |
| 03 | Exibição de nomes em ordem inversa |
| 04 | Cálculo da média das alturas |
| 05 | Soma separada dos números pares e ímpares |
| 06 | Identificação do maior e do menor valor |
| 07 | Ordenação de valores em ordem crescente |
| 08 | Busca de um número e exibição de sua posição |
| 09 | Contagem de números maiores que 10 |
| 10 | Exibição do dobro dos valores armazenados |

## Como executar

```bash
javac PrimeiroSemestre/Vetores/Exercicio01.java
java PrimeiroSemestre.Vetores.Exercicio01
```
