# Métodos

Exercícios da disciplina de Programação Orientada a Objetos voltados à criação e à chamada de métodos em Java.

| Exercício | Conteúdo praticado |
|---|---|
| 01 | Quatro operações matemáticas com métodos |
| 02 | Potenciação implementada com método e estrutura `for` |
| 03 | Radiciação inteira por meio de métodos |
| 04 | Ordenação de três números |
| 05 | Operações com matriz: preenchimento, exibição, pares e múltiplos de 5 |
| 06 | Conversão entre reais, dólares, libras, francos e ienes |
| 07 | Verificação de divisibilidade entre dois números |
| 08 | Identificação do mês a partir do número informado |
| 09 | Cálculo da média final da disciplina de POO |
| 10 | Cálculo de fatorial |

## Observações

- No exercício 05, o enunciado menciona a ordenação da matriz, mas a implementação original contém métodos para preencher, mostrar, filtrar pares e filtrar múltiplos de 5.
- No exercício 08, o enunciado menciona uma data no formato `dd/mm/aaaa`, enquanto a implementação original recebe dia, mês e ano separadamente.

## Como executar

```bash
javac SegundoSemestre/ProgramacaoOrientadaObjetos/Metodos/Exercicio01.java
java SegundoSemestre.ProgramacaoOrientadaObjetos.Metodos.Exercicio01
```
