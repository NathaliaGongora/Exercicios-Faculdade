# Lista 01 — Revisão de algoritmos

Primeira lista da disciplina de Programação Orientada a Objetos, desenvolvida como revisão dos principais conteúdos de algoritmos estudados anteriormente.

| Exercício | Conteúdo praticado |
|---|---|
| 01 | Soma e média de quatro notas |
| 02 | Dia da semana com `switch case` |
| 03 | Comparação entre dois números |
| 04 | Identificação do maior número ou igualdade |
| 05 | Verificação de número par ou ímpar |
| 06 | Saudação conforme o nome e o sexo informado |
| 07 | Média das idades das pessoas maiores de idade |
| 08 | Números pares dentro de um intervalo |
| 09 | Cálculo de fatorial com `while` |
| 10 | Seleção de um nome armazenado em vetor |

## Como executar

```bash
javac SegundoSemestre/ProgramacaoOrientadaObjetos/Lista01/Exercicio01.java
java SegundoSemestre.ProgramacaoOrientadaObjetos.Lista01.Exercicio01
```
