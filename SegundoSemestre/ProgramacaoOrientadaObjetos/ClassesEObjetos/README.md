# Classes e objetos

Exercícios da terceira aula de Programação Orientada a Objetos, voltados à criação de classes, atributos, métodos e objetos em Java.

| Classe | Conteúdo praticado |
|---|---|
| `Aluno` | Notas, cálculo de média e situação acadêmica |
| `Carro` | Estado do objeto, aceleração e frenagem |
| `ContaBancaria` | Depósito, saque e consulta de saldo |
| `Funcionario` | Dados profissionais e aumento salarial |
| `Lampada` | Alteração e consulta do estado ligado/desligado |
| `Livro` | Empréstimo, devolução e disponibilidade |
| `Pessoa` | Armazenamento e exibição de dados pessoais |
| `Produto` | Criação de objetos e cálculo de lucro |
| `Retangulo` | Cálculo de área e perímetro |
| `Televisao` | Controle de estado, canal e volume |

## Observação

Os exemplos são introdutórios e utilizam acesso direto aos atributos. Encapsulamento, construtores e validações ainda não fazem parte destes códigos.

## Como executar

```bash
javac SegundoSemestre/ProgramacaoOrientadaObjetos/ClassesEObjetos/Aluno.java
java SegundoSemestre.ProgramacaoOrientadaObjetos.ClassesEObjetos.Aluno
```
