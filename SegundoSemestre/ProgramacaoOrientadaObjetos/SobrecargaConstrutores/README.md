# Sobrecarga de construtores

Exercícios de Programação Orientada a Objetos que demonstram a criação de diferentes construtores para a mesma classe. Cada construtor recebe uma combinação distinta de parâmetros e permite criar objetos com diferentes níveis de informação.

| Classe | Sobrecargas demonstradas |
|---|---|
| [Aluno.java](Aluno.java) | Cadastro com uma, duas, três ou quatro avaliações |
| [Carro.java](Carro.java) | Cadastro com marca e modelo, com ano ou com todos os dados |
| [Computador.java](Computador.java) | Cadastro somente com marca, com especificações ou com todos os dados |
| [ContaBancaria.java](ContaBancaria.java) | Cadastro somente com titular, com número da conta ou com saldo inicial |
| [Filme.java](Filme.java) | Cadastro somente com título, com gênero e duração ou com todos os dados |
| [Funcionario.java](Funcionario.java) | Cadastro somente com nome, com cargo ou com salário |
| [Livro.java](Livro.java) | Cadastro com título e autor, com páginas ou com todos os dados |
| [Pessoa.java](Pessoa.java) | Cadastro somente com nome, com idade ou com todos os dados físicos |
| [Produto.java](Produto.java) | Cadastro completo ou cálculo automático de preço e validade |
| [Retangulo.java](Retangulo.java) | Criação de retângulo ou quadrado conforme os parâmetros |

## Conteúdos praticados

- declaração de construtores;
- uso de `this` para diferenciar atributos e parâmetros;
- sobrecarga por quantidade de parâmetros;
- inicialização de valores padrão;
- criação de objetos com diferentes assinaturas.

## Execução

A partir da raiz do repositório, compile e execute uma classe. Exemplo:

```bash
javac SegundoSemestre/ProgramacaoOrientadaObjetos/SobrecargaConstrutores/Carro.java
java SegundoSemestre.ProgramacaoOrientadaObjetos.SobrecargaConstrutores.Carro
```
